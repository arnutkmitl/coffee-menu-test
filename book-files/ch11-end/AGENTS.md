# กติกาสำหรับผู้ช่วย AI ในโปรเจกต์ coffee-menu

## ขอบเขตงาน
- ทำงานบน branch ที่ผู้ใช้สร้างไว้เท่านั้น ห้าม commit หรือ push ลง main
- แก้เฉพาะไฟล์และส่วนที่โจทย์ระบุ ห้ามจัดรูปแบบไฟล์ใหม่ทั้งไฟล์ ห้ามเปลี่ยนชื่อฟังก์ชันหรือตัวแปรเดิม
- ห้ามเปลี่ยนชื่อเมนู ราคา หรือข้อความที่ผู้ใช้เห็น ถ้าโจทย์ไม่ได้สั่ง

## ความปลอดภัย
- ห้ามใส่ API key รหัสผ่าน หรือ token ลงในโค้ด ให้อ่านจากไฟล์ .env ซึ่งอยู่ใน .gitignore
- ห้ามแก้ .gitignore เพื่อเอา .env ออก

## เมื่อทำงานเสร็จ
- สรุปรายชื่อไฟล์ที่แก้และเหตุผลของแต่ละไฟล์
- บอกวิธีทดสอบ โดยอ้างอิงหัวข้อ "วิธีทดสอบ" ใน README.md

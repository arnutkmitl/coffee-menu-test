# บ้านสวนคาเฟ่

หน้าเว็บเมนูของร้านกาแฟสมมติ (ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่าง) ใช้เป็นโปรเจกต์ฝึกในหนังสือ Git & GitHub สำหรับนักพัฒนาแอปยุค AI

## วิธีเปิดแอป

เปิดดูแอปออนไลน์ได้ที่ https://somchai-dev.github.io/coffee-menu/ หรือดาวน์โหลดหรือ clone โปรเจกต์นี้ แล้วดับเบิลคลิกไฟล์ index.html เพื่อเปิดในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์

- แสดงเมนูเครื่องดื่มและขนมพร้อมราคาและคำอธิบาย
- ปุ่มเรียงตามราคา
- ปุ่มสลับธีมมืด
- ปุ่มกรองเมนูตามหมวด
- ตะกร้าสาธิต รวมจำนวนและราคา (ไม่มีการชำระเงินจริง)

## วิธีทดสอบ

ชุดทดสอบอัตโนมัติ: รัน node --test (ต้องมี Node.js) GitHub Actions รันชุดนี้ให้ทุก PR

ทดสอบด้วยตนเองในเบราว์เซอร์:

1. เมนูแสดงครบแปดรายการ ลาเต้ราคา 60 บาท
2. กดปุ่มเรียงตามราคา ชาไทย 40 บาทต้องขึ้นบนสุด
3. กดปุ่มสลับธีมมืด พื้นหลังต้องเปลี่ยนเป็นสีเข้มและอ่านราคาออก
4. กดปุ่มกาแฟ ต้องเหลือห้ารายการ กดปุ่มชา ต้องเหลือชาไทยรายการเดียว กดปุ่มขนม ต้องเหลือสองรายการ กดปุ่มทั้งหมด ต้องกลับมาแปดรายการ
5. กรองหมวดกาแฟแล้วกดเรียงตามราคา ต้องเรียงเฉพาะห้ารายการนั้น
6. กดเพิ่มลาเต้และบราวนี่ สรุปตะกร้าต้องเป็น 2 รายการ รวม 120 บาท
7. กดล้างตะกร้า สรุปต้องกลับเป็น 0 รายการ รวม 0 บาท

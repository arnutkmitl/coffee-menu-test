# บ้านสวนคาเฟ่

หน้าเว็บเมนูของร้านกาแฟสมมติ (ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่าง) ใช้เป็นโปรเจกต์ฝึกในหนังสือ Git & GitHub สำหรับนักพัฒนาแอปยุค AI

## วิธีเปิดแอป

ดาวน์โหลดหรือ clone โปรเจกต์นี้ แล้วดับเบิลคลิกไฟล์ index.html เพื่อเปิดในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## ฟีเจอร์

- แสดงเมนูเครื่องดื่มพร้อมราคาและคำอธิบาย
- ปุ่มเรียงตามราคา
- ปุ่มสลับธีมมืด
- ปุ่มกรองเมนูตามหมวด

## วิธีทดสอบ

1. เมนูแสดงครบหกรายการ ลาเต้ราคา 60 บาท
2. กดปุ่มเรียงตามราคา ชาไทย 40 บาทต้องขึ้นบนสุด
3. กดปุ่มสลับธีมมืด พื้นหลังต้องเปลี่ยนเป็นสีเข้มและอ่านราคาออก
4. กดปุ่มกาแฟ ต้องเหลือห้ารายการ กดปุ่มชา ต้องเหลือชาไทยรายการเดียว กดปุ่มทั้งหมด ต้องกลับมาหกรายการ
5. กรองหมวดกาแฟแล้วกดเรียงตามราคา ต้องเรียงเฉพาะห้ารายการนั้น
